# Brilliant Law Website Concepts

GitHub Pages-ready comparison site containing six homepage concepts for Brilliant Law Office PLLC.

## Publish on GitHub Pages

1. Create a GitHub repository, for example `brilliant-law-concepts`.
2. Upload **the contents of this folder** to the repository root. `index.html` and `.nojekyll` should be at the top level.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will publish the comparison page at a URL similar to:
   `https://YOUR-USERNAME.github.io/brilliant-law-concepts/`

Each concept will also have its own shareable URL:

- `/concept-1-classic/`
- `/concept-2-editorial/`
- `/concept-3-modern/`
- `/concept-4-heritage/`
- `/concept-5-private-counsel/`
- `/concept-6-clear-authority/`

## Notes

- `.nojekyll` is included for straightforward static hosting.
- The concept folders contain their own local image assets where needed.
- These are design concepts, not production legal pages. Review legal claims, jurisdictions, disclaimers, testimonials, privacy terms, accessibility and attorney-advertising requirements before launch.
