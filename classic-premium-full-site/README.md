## Important production notes
1. The current live site displays inconsistent national phone numbers. This prototype uses **(833) 296-8529**, which matches the vanity spelling 2-YOU-LAW and the current contact/footer content. Confirm before launch.
2. Legal claims, jurisdiction statements, practice availability, attorney advertising language, privacy policy, intake disclaimers, testimonials and fee/consultation wording require attorney review.
3. The static contact form is intentionally non-functional.
4. The current live Civil Litigation page appears to contain duplicated Business-page copy; this prototype does not reproduce that duplication.
5. The current live FAQ contains placeholder content; this prototype supplies proposed firm-specific FAQs for review.

## Oxygen 6
The shared CSS tokens and repeated components are intentionally structured so they can map cleanly to Oxygen variables, classes, components, and templates.
